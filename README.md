# ⚡ EVCharge - Electric Vehicle Charging App

A Flutter mobile app to locate electric vehicle charging stations and request roadside assistance in case of emergencies.

## 🚀 Features

- Interactive map using Google Maps API
- User location tracking and permission handling
- Firebase Authentication and Firestore integration
- REST API for charging station data
- Responsive UI for Android & iOS
